# Learn rat-stack

Read the project law before changing code.

1. Read `AGENTS.md` for constraints and validation.
2. Read `VISION.md` for product intent.
3. Define behavior once as a schema-typed capability.
4. Add it to the capability list.
5. Let the CLI, HTTP, MCP, and code-mode projections expose it.
6. Run `pnpm turbo run check test build`.
